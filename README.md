# Beep

Beep is a browser-based Blackjack-inspired card game built with HTML, CSS, and JavaScript. Players start rounds, draw cards, manage virtual credits, and aim to reach 21 without going over.

The project focuses on interactive gameplay, DOM manipulation, JavaScript logic, and responsive web design.

## Features

- Interactive card gameplay
- Virtual credit balance
- Round entry and card draw costs
- Win and loss conditions
- Option to start a new round
- Responsive user interface

## How to Play

1. Start a round by selecting **Start Game**.
2. Your starting cards and total will appear on the screen.
3. Select **Draw New Card** to receive another card, provided you have enough credits.
4. Aim for a total of 21 without exceeding it.
5. Select **New Game** to prepare for another round.

## Game Rules

| Action | Virtual Credits |
| --- | ---: |
| Starting balance | 1,000,000 |
| Starting a round | 200,000 |
| Drawing another card | 100,000 |
| Winning payout | 2,100,000 |

The game uses a simplified Blackjack-inspired rule system. A total of 21 wins, a total below 21 allows the player to draw again, and a total above 21 results in a loss.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build tools are required for the basic version.

## Virtual Credits

Beep uses fictional credits for gameplay. Credits have no cash value and cannot be exchanged for real money. The game is intended for entertainment and as a personal web development project.
